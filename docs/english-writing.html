뉴스 영어 노트

영어 기사를 읽으며 표현을 익히고, 직접 쓴 요약을 고쳐 보세요.

기사로 공부하기

  1. 원문 기사를 연 뒤 Chrome 확장 메뉴에서 뉴스 영어 노트를 누르세요. 기사 옆에 작성 창이 열립니다.
  2. 영어 단어나 문장을 드래그하면 한국어 뜻이 선택한 위치에 뜹니다.
  3. 나의 영어 요약에 직접 쓴 뒤 내 요약 첨삭받기를 누르세요. 수정할 표현과 빠진 내용의 원문 근거를 확인할 수 있습니다.
  4. 저장한 글에서 초안과 회차별 첨삭을 다시 여세요. 글을 고치고 첨삭을 다시 받으면 새 작성본이 기록됩니다.

처음 사용하는 Windows 노트북에서

  1. 프로젝트를 노트북에 저장하세요. Python에서 python -m pip install -r requirements.txt로 의존성을 설치하고 프로젝트의 .env에 GROQ_API_KEY를 설정하세요. 기존 뉴스 발행기의 키를 사용할 수 있습니다.
  2. 프로젝트의 study/connect.cmd를 실행해 이 노트북의 AI 연결을 등록하세요.
  3. Chrome 주소창에서 chrome://extensions를 열어 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다에서 study/extension 폴더를 선택하세요.

드래그한 표현과 주변 문장, 첨삭을 요청한 본문과 요약은 Groq로 전송됩니다. 작성본과 첨삭 기록은 사용 중인 Chrome 프로필에 저장됩니다.
